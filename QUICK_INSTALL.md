# 📱 ViMusic - One-Click Install (Super Easy!)

## **For Users: Download & Install in 5 Minutes**

### **What You Need (One Time)**
- ✅ Android Studio (free) - [Download here](https://developer.android.com/studio)
- ✅ USB cable to connect your phone

---

## **🚀 Super Easy Steps (5 minutes total)**

### **Step 1: Download the Code (2 minutes)**
Click this link and download as ZIP:
```
https://github.com/mohdrahil327/ViMusic/archive/refs/heads/rahil729-vimusic-task.zip
```

Or use this direct download link (copy-paste in browser):
```
https://github.com/mohdrahil327/ViMusic/archive/refs/heads/rahil729-vimusic-task.zip
```

Extract the ZIP file (any folder is fine).

---

### **Step 2: Open in Android Studio (1 minute)**
1. Open Android Studio
2. Click **File** → **Open**
3. Select the extracted **ViMusic** folder
4. Click **Open**
5. Wait for bottom right "Gradle sync" to finish (shows checkmark ✅)

---

### **Step 3: Build APK (1 minute)**
1. Click **Build** menu (top of screen)
2. Click **Build Bundle(s) / APK(s)**
3. Click **Build APK(s)**
4. Wait for notification "Build Complete" (takes 1-2 minutes)
5. Click **Show in Folder**
6. You'll see a file: `app-debug.apk`

---

### **Step 4: Install on Phone (1 minute)**
**Option A: USB Cable (Recommended)**
1. Plug your phone into computer with USB
2. In Android Studio, click **Run** → **Run 'app'**
3. Select your phone
4. Click **OK**
5. App automatically installs! ✅

**Option B: Manual Install**
1. Copy `app-debug.apk` to your phone via USB
2. On phone, open file manager
3. Find `app-debug.apk`
4. Tap it
5. Tap **Install**
6. Done! ✅

## ❓ Problems?

**Android Studio won't open?**
- Download from: https://developer.android.com/studio

**Phone not showing?**
- Enable USB Debugging: Settings > Developer Options > USB Debugging (ON)
- If no Developer Options: Settings > About Phone > Build Number (tap 7 times)

**Gradle sync fails?**
- Click **File > Sync Now** again

**Still stuck?**
- Check EASY_INSTALL_GUIDE.md in the repo for more details
